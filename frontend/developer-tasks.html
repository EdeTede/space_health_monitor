Inspect the NASA-derived catalogue and edit its demo assumptions. IDs stay fixed. Default durations apply to newly added activities; workload, monitor offsets, category and oxygen changes recalculate existing activities, including historical simulations.

Fixed simulation rules

Stress accumulates over the previous 24 hours and is clamped to 0–100. Heart-rate offsets feed synthetic samples, not measured clinical records. Only linked, uninterrupted oxygen activities immediately before an EVA receive washout credit. General exercise, meals and rest receive no automatic DCS reduction. Existing scheduled durations and recorded baseline HR remain unchanged.

The planner averages duration-weighted elimination rates across oxygen segments. Equivalent VO₂ is a diagnostic value using the default exponential mapping. These rules live in planner-core.js; the editable parameters are above.
