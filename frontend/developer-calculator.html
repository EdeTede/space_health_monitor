Parser, fixed guards and model limitations

Supported: + − * / ^, parentheses, exp, log, pow, min, max, abs, sqrt. ATM = 14.696 and KPA = 101.325 are fixed unit conversions. No JavaScript is executed. Every expression can reference constants plus its listed inputs.

Fixed guards: inverse probabilities clamp to 1e−9…99.99%; rising DLCO assigns zero inferred VGE; personal factor is unavailable below 1% predicted VGE. Solvers return zero when q ≥ 1; exercise returns Infinity at zero oxygen time. No previous EVA means carryover = 1. Outputs must be finite and probabilities must remain 0–100%.

Closed-form solvers and inverse expressions must be edited consistently with forward equations. The sample validation grid checks finite results, not scientific validity or inverse consistency. The baseline DCS equation has no EVA-duration term: shortening EVA changes hyperoxic exposure, not baseline DCS. The planner uses duration-weighted segment rates for mixed oxygen activities.
